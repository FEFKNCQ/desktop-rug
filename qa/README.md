# 验证脚本与历史指标

`reference/` 中的文件是发布前筛选过的自动化结果，保留 4.6 性能对照和常规物理/材质/堆叠测试的依据。它们不包含原始个人姿态、桌面图标名、壁纸图片或运行缓存。

运行 `npm --prefix web test` 会在本目录根部生成新的结果；Git 默认忽略这些输出，不覆盖 `reference/`。没有必要把每次本机测试记录上传。

- `profile-contact.mjs`：纯合成场景下的碰撞计算耗时。
- `drag-stress.mjs`：默认从合成姿态开始的高强度拖动；如果本地存在旧版形状备份，会沿用它以复测历史结果。历史 baseline 模式需要维护者自备旧版源码。
- `check-saved-shape.mjs`：只检查本机保存的形状，首次安装尚无状态文件时不能运行。
- `package-v4.py`：沿用历史脚本名，构建当前版本便携包。

历史性能数值依赖测量机器和轨迹，不用于 CI 的固定毫秒阈值。极端高频揉叠仍有穿插，详见 `reference/verification-v46.txt`。
