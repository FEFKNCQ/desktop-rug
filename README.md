# DesktopRug · Windows 桌面绒毯

把 Windows 桌面变成一块地板，在上面铺一张可以拖动、掀起、折叠、缩放的毯子；拿起扫帚，直接推动真实桌面图标，把它们扫成一堆，或慢慢扫到毯子下面。

当前版本 **4.6.1**。完整 C#、Electron、Three.js、布料物理与交互源码均在仓库中，内置贴图一并提供。支持本地运行和继续开发；无账号、API Key、云服务或数据库依赖。

![风格面板与可折叠纸张](docs/images/panel.png)

> 图中图标来自预览模式的合成示例，不是个人桌面截图。真实桌面模式直接推动 Windows 原生图标，文件仍在原来的位置。

**快速入口：** [交给 AI 部署](docs/AI_DEPLOY.md) · [开发指南](docs/DEVELOPMENT.md) · [隐私说明](docs/PRIVACY.md) · [素材来源与许可范围](ASSET_NOTICE.md)

## 可以做什么

- **拖动绒毯**：抓住局部提起、拉扯、折叠；松手回落，保留部分褶皱。支持整块平移、缩放、旋转与一键铺平。
- **切换地板和材质**：桌面壁纸与毯子分别选择、分别保存，切换款式沿用当前形状和位置。
- **用扫帚整理**：扫帚跟随系统鼠标，按住左键推着真实图标移动、挤成堆；可以慢慢推进毯子下面。右键放下，保留位置。
- **一键分类**：分为软件入口、文件/PDF、图片三组。文件夹、压缩包、音视频、安装包、未知扩展名、失效快捷方式和系统图标都有处理规则。
- **恢复与撤销**：最近一次清扫/整理可撤销；备份原壁纸及最初图标布局。原壁纸有独立图片副本，也能重新指定图片。
- **性能优化**：GPU 绘制毛发，Worker 计算布料；静止后停止模拟/重绘，隐藏时暂停；高频输入合并，减少拖动位置积压。

## 自己安装与运行

### 环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位；当前显示在主屏工作区 |
| 图形 | 可用的硬件图形加速与 WebGL；性能取决于 CPU、显卡和折叠复杂度 |
| Node.js | x64，至少 22.12；本地使用 Node.js 24 测试 |
| 编译 | Windows .NET Framework 4.x 自带的 `Framework64/v4.0.30319/csc.exe` |
| 工具 | PowerShell；用 `git clone` 时需 Git |
| 网络 | 初次安装从 npm 与 GitHub 下载依赖；安装后应用可离线运行 |

不要求 Visual Studio、.NET 8 SDK、管理员运行、Python 或 AI API Key。Python 3 仅在自行制作便携 ZIP 时需要。

### 一键构建

在 PowerShell 中运行：

```powershell
git clone https://github.com/LongJingSU/desktop-rug.git
cd desktop-rug
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Preview
```

脚本使用锁文件安装 Electron **44.5.1** 与 Three.js **0.185.0**，构建 `DesktopRug.exe`，检查代码与资源，然后打开预览窗口。`ExecutionPolicy Bypass` 只对这次 PowerShell 进程生效，不永久修改系统执行策略。

预览完成后关闭预览窗口，再启动真实桌面版：

```powershell
.\DesktopRug.exe
```

也可以不带参数运行 `setup.ps1`，只安装和构建；或用 `-Start` 在构建后直接进入桌面。以后双击 `DesktopRug.exe` 即可，无需重复安装。请把整个项目保存在可写目录，保留 `web` 和 `assets`，不能只拷贝 EXE。

### 手动构建与测试

```powershell
npm ci --prefix web
node .\web\node_modules\electron\install.js
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
npm --prefix web run check
npm --prefix web test
.\DesktopRug.exe --gpu-preview
```

默认八组测试不调用真实桌面图标/壁纸操作。修改 JS 后重启即可；修改 C# 后需要重新构建。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 按住毯子拖动 | 抓取局部、提起、拉扯、形成折叠 |
| Shift + 拖动 | 整块平移 |
| 鼠标滚轮 / `＋` / `−` | 放大、缩小 |
| Shift + 滚轮 | 旋转 |
| 双击 / **铺平** | 清除褶皱并展开 |
| **扫帚** / 右下方扫帚图案 | 拿起扫帚，保留毯子现状 |
| 拿起后按住左键扫动 | 推动接触到的图标，图标之间可挤成堆 |
| 右键 | 放下扫帚，保留图标位置 |
| **一键整理** | 将图标按类型摆成三组 |
| **撤销布局** | 恢复最近一次清扫/整理前的坐标 |
| **风格** | 更换壁纸与毯子；选择自动保存 |
| Ctrl + Alt + R | 显示 / 隐藏 |
| Ctrl + Alt + B | 拿起 / 放下扫帚 |
| Ctrl + Alt + Shift + Q | 退出 |

**一键整理的分类：**

- 软件入口：程序、应用/网页快捷方式、回收站、此电脑等系统入口；失效或特殊应用快捷方式保留为入口。
- 文件 / PDF：PDF、办公文档、文件夹、压缩包、音视频、安装包和未知类型；无扩展名文件也在这里。
- 图片：照片、截图、SVG、HEIC、AVIF、RAW 等常见图片。

能读取目标的快捷方式按目标类型分类。整理尽量避开毯子，空间不足时收紧排列，并提示被毯子遮盖的图标。所有操作只改图标坐标，不新建分类文件夹，也不搬动文件本体。

## 原壁纸、退出与恢复

**首次启动真实桌面模式**会备份原壁纸与图标布局，设置木地板，并关闭图标自动排列/对齐网格；预览模式不会执行这一步。若元气桌面等程序覆盖原生桌面，需要退出其桌面覆盖功能后才能看到本程序。

在 **风格 → 原壁纸** 或托盘右键的壁纸菜单中恢复。程序保存独立图片副本，减少原图缓存被清理后的恢复失败；无法获取原图时可用 **重新指定原壁纸…** 选择文件。恢复静态图片不等于恢复第三方软件的动态壁纸播放。

托盘右键还能恢复最初图标布局与网格设置。正常退出保留当前壁纸和自由摆放设置，**不会自动全部还原**。要彻底停用，可先恢复原壁纸、恢复布局，再退出。

```powershell
.\DesktopRug.exe --exit
```

不安装后台服务，不自动添加开机启动。快捷键被别的程序占用时使用托盘菜单。

## 性能和当前边界

4.6 优先优化高强度来回拖动：复用碰撞候选、缓存网格连接关系、减少重复几何计算，并合并旧鼠标位置。保持布料网格、碰撞迭代次数与毛发层数。

在相同初始形状与拖动轨迹的本地测试中，长绒模拟中位耗时约 **15.93 → 13.11 ms**，短绒约 **23.99 → 17.68 ms**。三种材质、共十二轮常规堆叠检查未检测到相交。完整条件和结果见 [4.6 验证记录](qa/reference/verification-v46.txt)。这些是应用模拟数据，不是所有设备的帧率保证。

目前仍有以下限制：

- 极端快速揉叠可能短暂卡顿或穿插，碰撞和毛发均为实时近似。
- 当前主要支持主屏工作区域，多屏独立毯子尚未实现。
- 当前一次显示一款毯子/纸张，不是多张独立毯子同时堆叠。
- 卫生纸不支持撕裂；地板是静态壁纸，不模拟地砖碰撞。
- 当前源码保留旧 WPF 路径；默认使用 GPU 版。`--self-test` / `--preview` 等旧参数不能替代新版测试，应使用 `--gpu-preview`。

## 常见问题

**启动后看不到毯子：** 先回到桌面，按 Ctrl+Alt+R 或用托盘显示；检查第三方桌面软件是否覆盖，再用 `--gpu-preview` 判断渲染是否正常。首次着色器准备可能稍慢。

**图标被遮住：** 把毯子掀开、移动或缩小，或隐藏程序。扫帚不会删除文件。

**`npm ci` 失败：** 检查 Node 版本，以及 npm registry / GitHub 下载连通性。Electron 44 的运行时按需下载，`setup.ps1` 会显式调用它的安装器；手动构建请不要漏掉上面的 `install.js` 命令。不要为绕过错误删除锁文件。

**构建提示 EXE 被占用：** 先从托盘退出本项目，再构建。无需结束资源管理器。

**别人下载后会拿到我的壁纸吗：** 不会。仓库不包含个人壁纸、原始桌面截图、图标布局、账号缓存和运行记录；每个人首次运行在自己的电脑上建立备份。提交新内容前仍应检查 [隐私说明](docs/PRIVACY.md)。
