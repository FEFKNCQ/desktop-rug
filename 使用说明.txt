桌面绒毯 4.6.1 · 新增海洋绮梦短绒风格

启动
双击 DesktopRug.exe 或桌面上的“桌面地毯”。回到桌面即可看到。
便携包请完整解压，保留 assets 和 web 文件夹。无需安装、管理员权限或联网。
首次使用会备份壁纸及图标布局，设置木地板壁纸，并关闭图标自动排列和对齐网格。
已经使用过的个人设置与备份会保留。元气桌面若覆盖原生桌面，请先退出它的桌面功能。
再次运行切换显示状态。桌面“退出桌面地毯”或托盘菜单可退出。

手势
直接抓住毯子任意位置拖动：局部提起、拉扯和折叠；松手柔软回落。
部分拉扯形成的褶皱会留下，继续抓住可以改变形状。
Shift + 拖动：整块平移。
滚轮 / ＋ / −：缩放；Shift + 滚轮：旋转。
双击 / “铺平”：清除褶皱，重新展开。
Ctrl+Alt+R 显示或隐藏；Ctrl+Alt+Shift+Q 退出。
隐藏时暂停布料计算；静止后停止计算和画面重绘。

扫帚
点击“扫帚”、右下方扫帚图案，或按 Ctrl+Alt+B。
拿起扫帚时保留毯子的大小、位置和褶皱。扫帚跟随系统光标显示。
等图标准备好，按住左键，让扫帚头推动图标。图标沿扫动方向移动，相互挤成堆。
可以在任意地方堆放，松手后停住，再次扫动继续推；不会自动飞向毯子。
只有推到毯子当前覆盖的地方，图标才被遮住。可以一点点推进去。
右键放下扫帚，图标保留推到的位置，恢复普通桌面操作。
掀开毯子可以找回图标。“撤销布局”恢复最近一次清扫或整理前的坐标。
每次拿起扫帚是一轮，第一次扫到文件时保存备份。
清扫直接移动 Windows 原生图标，保留原来的图案、大小与文字，不先替换成图片。
回收站、此电脑、控制面板等系统入口也可以推动。文件和文件夹留在原路径。
桌面枚举、读取图标、位置变更和撤销在独立进程执行，不占用鼠标交互线程。

一键整理
点击右下角“一键整理”，把图标归成三组紧凑区域，并短暂显示分类名称和数量：
软件入口：程序、应用/网页快捷方式，以及回收站、此电脑等系统入口。
文件 / PDF：文档、PDF、文件夹、压缩包、音视频、安装包（如 MSI）和未知类型。
图片：常见照片、截图、SVG、HEIC、AVIF、RAW 等图像格式。
能读到目标的快捷方式按目标分类，指向 PDF 或图片的快捷方式会进入对应组。
失效或特殊应用快捷方式保留为入口；无扩展名文件、点号命名文件夹也会处理。
整理尽量避开当前毯子，空间不足时加密摆放；若仍需放在毯子下，会在提示中说明。
不移动文件的实际存储路径，不创建分类文件夹。点击“撤销布局”恢复整理前坐标。

风格
点击右下角“风格”，面板分为“桌面壁纸”和“毯子与纸张”两栏。
壁纸：木地板、红木地板、大理石瓷砖，或恢复原壁纸。托盘菜单也能切换。
材质：暖白长绒毯、秋日猫咪短绒毯、杰瑞钞票短绒毯、海洋绮梦短绒毯、柔白卫生纸。
三款图案按照提供的参考图重新制作；短绒贴服，图案随布面弯曲。
卫生纸是可切换的单张薄纸材质，带细压纹，可拖动、折叠和缩放；不模拟撕裂。
每次显示一款毯子或纸张。切换沿用当前位置、大小和形状，不自动铺平。
选择自动保存，下次启动继续使用。初次载入贴图时短暂显示准备提示。
原壁纸现在保存独立的图片副本，避免元气/Windows 清理缓存后失效。
在 Windows 中换上新图片后，再切换地板，会备份这张新图片。
也可点“重新指定原壁纸…”选择图片。退出元气后可恢复静态图片，不接管元气的动态壁纸播放器。
壁纸由 Windows 静态显示。短绒停用长毛束；卫生纸停用全部绒毛层。
assets/wallpapers.json 和 assets/rugs.json 管理风格列表，后续新款加入对应栏。

这版的变化
4.6.1 新增蓝白海洋绮梦短绒印花；花边与蝴蝶结随布面弯曲，沿用短绒渲染和物理参数。
4.6 复用碰撞候选内存，缓存网格连接关系及每帧几何数据，减少密集折叠时的重复计算。
快速拖动采用确认式输入合并，保留最新待处理位置；整块平移累计位移，松手前按顺序提交最终位置。
鼠标捕获期间省去重复点击区域计算，松手后恢复更新。毛发层数、布料网格与碰撞迭代次数保持不变。
相同高强度轨迹下，长绒模拟中位耗时从 15.93 降至 13.11 ms；短绒从 23.99 降至 17.68 ms。
三种材质共 12 轮常规堆叠检查无相交；极端快速揉叠仍可能穿插或出现顿帧，尚未完全解决。

保留的功能与历史改进
透明窗口保持独立顶层，由桌面窗口拥有；不再作为图标窗口的子窗口，避免鼠标进入后把图标裁掉。
启动时等待布料首帧、着色器和绘制完成，再以零透明度定位至桌面层，最后显示。
扫动时按画面帧合并鼠标采样，先解决图标碰撞，再批量提交原生位置。
通过原生图标控件及时移动；同一时间最多一批在途，避免旧位置积压。
放下和正常退出时再同步最终布局。撤销保留原生布局恢复方式。
首次接触不再把图标突然推到扫帚的另一边，也不拉动已经落在扫帚后方的图标。
扫帚外观使用系统光标，避免网页里的扫帚元素等待下一次绘制。
原生图标视图全程保持显示，取消图标图片替身、预加载等待和原生视图隐藏。
保留旧版清扫视图遗留状态的恢复处理。
反复拿起/放下扫帚不会重复修改已经关闭的网格选项。撤销会等待在途清扫全部完成。
增加可见曲面细分、平滑的毛束法线与更柔和的照明；物理网格与拖动方式保留。
用 GPU 渲染替代旧版 WPF 透明窗口渲染；布料模拟在独立 Worker 执行。
暖白绒毛由 GPU 绘制，毛束随布料弯曲，不逐根进行 CPU 物理模拟。
取消单一圆柱卷折；加入柔软局部弯曲、地面摩擦、纤维弯曲滞后和拉伸限制。
抓取时选择最上方布面；碰撞覆盖三角布面和网格边缘，并限制穿过前一帧所在侧。
显示曲面与碰撞网格一致，避免平滑插值越过相邻层。高处抓取保持抬起高度。
旧版已经穿插的形状在加载时回退到安全形态；当前位置、大小和款式保留。
碰撞使用实时近似，极端快速揉叠仍需进一步检验；不承诺任意姿态完全无瑕疵。
本机 RTX 2060 自动拖动回放中，画面提交间隔中位数约 14 ms，95 分位约 21 ms。
4.1 实际鼠标交互记录中，中位数约 14 ms，95 分位约 28 ms。
4.4 相同轨迹的原生图标更新测试：普通 Shell 接口往返中位数约 18 ms；快速更新约 2 ms。
这次桌面回放中快速更新仍有约 50 ms 的离群值，不能保证任何情况下完全没有顿帧。
这些是应用更新数据，不是 Windows 合成器的逐帧呈现测量，也不是所有设备的帧率保证。

恢复与范围
托盘图标右键的“桌面壁纸”可选择地板或恢复原壁纸，也可恢复最初图标布局与网格设置。
退出保留壁纸和自由摆放设置。不自动开机启动、不安装后台服务。
目前显示于主屏工作区域。Windows 10/11 64 位，需要可用的硬件图形加速。
毛发和多层接触使用近似处理，并非影视级离线布料模拟。

本地文件
state.ini：位置、尺寸和旋转。plush-shape.json：新绒毯的形状。
cloth-shape.bin：旧版形状，不再用于新版。
original-wallpaper.txt / original-icon-flags.txt / original-icon-layout.bin：首次备份。
before-last-sweep.bin：最近一次清扫或整理前的布局备份。
web/profile：本地运行缓存。以上个人数据不会放入分享包。
status.txt：运行及桌面挂载状态。runtime.log：诊断记录。
revisions/v4 至 revisions/v4.5：此前版本备份。
floor-enabled.txt / rug-style.txt：当前壁纸和材质选择，不放入分享包。
wallpaper-backup：原壁纸独立副本及来源，不放入分享包。
push-active.txt：旧版视图交接标记；本版不再创建，启动时检查遗留恢复。

开发与验证
src + build.ps1：C# 启动器和原生桌面桥接；使用系统 .NET Framework 编译器构建。
web：Electron + Three.js 渲染、布料 Worker 与交互代码；便携包包含所需运行时。
DesktopRug.exe --gpu-preview：窗口预览，不移动真实桌面文件。
DesktopRug.exe --gpu-benchmark：实际桌面上的自动拖动回放，约 10 秒后退出。
node web/test-physics.mjs：连续拉扯、拉伸限制、松手回落、褶皱保留、休眠、缩放和铺平测试。
node web/test-pushing.mjs：接触推挤、碰撞成堆、停止与计算耗时测试。
node web/test-push-bridge.cjs：仅移动测试自己创建的临时桌面文件，验证任意位置保存、图标可见和精确撤销。
node web/test-organize.mjs：分类布局完整性、避开毯子、拥挤桌面回退、原生移动合并与最终位置测试。
node web/test-native-v43.cjs：13 个自建临时文件/快捷方式的分类、原生连续移动、整理和精确撤销。
Electron 运行 web --layer-test：连续 5 轮拿起/放下，检查无图标替身、原生图标持续显示、所有图标可推动和毯子形状不变。
Electron 运行 web --push-exit-test：清扫时故意终止渲染进程，检查恢复流程。仅开发验证使用。
node web/test-broom-live.mjs：每帧合并、首触不跳动、最终位置和慢响应时的积压限制。
node web/test-live-native.cjs：1 / 8 / 20 个真实临时图标的两条更新路径、原生显示与精确撤销对照。
node web/test-broom-desktop.cjs：完整桌面渲染窗口中的相同轨迹对照测试，仅推动自建临时图标。
node web/test-styles-native.cjs：壁纸切换与恢复、风格保存、重启读取、图标和备份不变。
node web/test-materials.mjs：三种材质拖动、落地、休眠、缩放与切换形状保留。
node web/test-stacking.mjs：三种材质各四轮角部堆叠，检查布面相交和模拟耗时。
node web/test-cloth-input.mjs：13,000 个高速输入样本、最终位置、累计平移与松手顺序。
Electron 运行 web --drag-benchmark：预览窗口中的高频拖动回放，不修改真实图标和壁纸。
qa/drag-stress-*.json、qa/drag-render-*.json 和 qa/verification-v46.txt：本版性能对照与限制。
qa/*v45*：风格与堆叠验证；qa/*v44* 和 qa/broom-desktop-baseline.json 保留扫帚性能对照。
旧版 --self-test、--preview 等命令只验证旧 WPF 组件，不代表新版验收。
